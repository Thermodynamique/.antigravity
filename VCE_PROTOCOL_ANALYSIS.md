# 🏛️ VCE — EXTRACTION COMPLÈTE EN 7 PHASES (PHASES A ➔ G)

| **Évolution 2** | *Temporal Cognition* | Trajectoire ($T_v/T_s$) | **Naviguer / Revenir** | Le temps est une primitive cognitive permettant d'explorer le passé, le présent et les futurs possibles. |

| **Évolution 5** | *Counterfactual Intelligence* | Branche (Fork), Hypothèse | **Comparateur CVI / Simuler** | Analyse contrefactuelle : "Que se serait-il passé si la décision $D_1$ avait été remplacée par $D_2$ ?" |
| **Évolution 6** | *Self-Improving Environment* | État (En Conflit/Incertain) | **Vérifier / Analyser** | Le système analyse son propre état, détecte ses incertitudes et génère des tâches auto-correctrices. |
| **Évolution 7** | *Cognitive Compiler* | Document, Projet | **Construire / Synthétiser** | Compilation de l'intention humaine brute en un sous-monde complet doté de variables et de structures. |
| **Évolution 8** | *Multi-Scale Cognition* | Entité, Relation | **Focus / Explorer** | Raisonnement simultané à plusieurs échelles (Monde ➔ Industrie ➔ Projet ➔ Tâche ➔ Atome). |
| **Évolution 9** | *Cognitive Compression* | Trajectoire, Preuve | **Synthétiser / Revenir** | Compression sémantique réversible permettant d'agréger 10 000 événements en un état synthétique. |
| **Évolution 10** | *World Model Federation* | Projet, Agent | **Relier / Déléguer** | Architecture distribuée et modulaire où plusieurs sous-mondes partagent leur état via Merkle DAG. |
| **Évolution 11** | *Collective Cognition* | Agent, Preuve | **Déléguer / Exécuter** | Société d'agents collaborant sur la même représentation du monde. |
| **Évolution 12** | *Human + AI Workspace* | Entité, Action | **Décider / Modifier** | L'humain passe de simple "prompt operator" à directeur d'environnement cognitif. |
| **Évolution 13** | *Real-Time World Synchronization*| État (Actuel), Preuve | **Suivre / Vérifier** | Ancrage continu du monde cognitif avec la réalité via capteurs, API et logs. |
| **Évolution 14** | *Autonomous Research Loops* | Hypothèse, Résultat | **Explorer / Simuler** | Boucles d'investigation autonomes poursuivies jusqu me d'atteindre le seuil de confiance CVI. |
| **Évolution 15** | *Cognitive Digital Twin* | Entité, Relation | **Simuler / Décider** | Jumeau numérique cognitif global d'une organisation ou d'une invention. |
| **Évolution 16** | *Deterministic Replay* | Trajectoire (SHA-256) | **Vérifier / Revenir** | Rejeu déterministe de toute décision passée à la microseconde près. |

| **Évolution 19** | *Merkle DAG Proof Anchor* | Preuve (SHA-256) | **Vérifier / Suivre** | Certification cryptographique permanente de chaque atome et livrable. |
| **Évolution 20** | *Emergent World Synthesis* | Domaine, Résultat | **Synthétiser / Construire**| Émergence continue d'un modèle global par auto-organisation du Canvas. |

## 🧭 PHASE B : Séquençage des 15 Use Cases (Parcours Utilisateurs Exacts)

1. **R&D / Recherche Scientifique** : Intention ➔ Entrer Domaine ➔ Explorer Publications ➔ Sélectionner Hypothèse ➔ Simuler Impact ➔ Déléguer Research Agent ➔ Synthétiser Preuve.
2. **IP / Brevets & Claims** : Intention ➔ Entrer Techno ➔ Explorer Antériorités ➔ Sélectionner Claim ➔ Comparer Invention vs Brevet X ➔ Vérifier Antériorité Zéro ➔ Décider Dépôt.
3. **Développement Logiciel / Code** : Intention ➔ Entrer Repo ➔ Explorer AST ➔ Sélectionner Composant ➔ Modifier Code (Monaco) ➔ Simuler Cascade Refactor ➔ Exécuter Merger.
4. **Codage Agentique Autonome** : Intention ➔ Entrer Mission ➔ Explorer Zone ➔ Sélectionner Contrainte ➔ Déléguer Agent Refactor ➔ Vérifier Assertion CVI ➔ Décider Validation.
5. **Debugging & Traçabilité Causale** : Intention ➔ Entrer Symptôme ➔ Explorer Traces ➔ Sélectionner Event Suspect ➔ Comparer State Before vs After ➔ Simuler Modif ➔ Décider Fix.
6. **Organisation & Prise de Décision** : Intention ➔ Entrer Projet ➔ Explorer Data ➔ Sélectionner Risque ➔ Comparer Scénarios ➔ Simuler Impact Marché ➔ Décider Stratégie.
7. **Audit & Conformité Réglementaire** : Intention ➔ Entrer Norme ➔ Explorer Relevés ➔ Sélectionner Clause ➔ Comparer Pratique vs Standard ➔ Vérifier SHA-256 ➔ Synthétiser Rapport.
8. **Analyse de Risque Financier** : Intention ➔ Entrer Portefeuille ➔ Explorer Variables ➔ Simuler Choc ➔ Comparer Stratégies A/B ➔ Décider Arbitrage.
9. **Ingénierie & Design Système** : Intention ➔ Entrer Sous-Système ➔ Explorer Arborescence ➔ Sélectionner Spécification ➔ Modifier In-Situ ➔ Synthétiser Orbe Certifié.
10. **Stratégie Produit & Roadmap** : Intention ➔ Entrer Produit ➔ Explorer Feedback ➔ Simuler Lancement ➔ Comparer Scénarios ➔ Décider Orientation.
11. **Veille Stratégique Concurrentielle** : Intention ➔ Entrer Secteur ➔ Explorer Signaux ➔ Relier Concurrents ➔ Simuler Mouvements ➔ Synthétiser Orbe.
12. **Gestion de Crise & Résolution D'Incidents** : Intention ➔ Entrer Incident ➔ Explorer Multi-Logs ➔ Comparer Hypothèses ➔ Déléguer Sentinel ➔ Exécuter Correctif.
13. **Recherche Clinique & Médicale** : Intention ➔ Entrer Protocole ➔ Explorer Cohortes ➔ Comparer Effets ➔ Vérifier Épreuve ➔ Décider Publication.
14. **Négociation Contractuelle & Juridique** : Intention ➔ Entrer Contrat ➔ Explorer Clauses ➔ Comparer Versions V1 vs V2 ➔ Vérifier Risques ➔ Modifier Termes.
15. **Conception d'Architecture Système AI** : Intention ➔ Entrer Topologie ➔ Explorer Graphe Agent ➔ Simuler Charge ➔ Comparer Topologies ➔ Décider Déploiement.

## 📊 PHASE C : Intersection & Matrice d'Universalité

Chaque action universelle s'applique de manière orthogonale et prévisible sur chacun des domaines d'application, garantissant l'absence de comportement sur-mesure codé en dur.

---

## 🧬 PHASE D : Formalisation de la Grammaire d'Actions Réduite

```
Action := Entrer(Objet) | Explorer(Fichiers | Discussion) | Sélectionner(Atomes) | Comparer(Atomes >= 2) | Modifier(Humain | Agent) | Simuler(Branche) | Décider(Validation) | Synthétiser(Livrable)
```

---

## 🖼️ PHASE E : Définition des Rendus Visuels Minimaux par Action

- **Entrer / Explorer** : Dépliage spatial in-situ de la zone avec l'arborescence des atomes et le fil de discussion IA.
- **Modifier** : Panneau d'édition plein écran avec textarea/Monaco/BlockNote pour l'humain ou délégation avec animation orbitale d'agent.
- **Comparer** : Surimpression dépolie de la `CentralComparisonTable` avec alignement colonne par colonne des atomes cochés.
- **Synthétiser** : Cristallisation d'un nœud Livrable Orbe Certifié SHA-256 sur le Canvas.

---

## 🔄 PHASE F : Formalisation de la Grammaire d'Interface (Transitions & Feedback)

- **Fondus & Zoom** : Transition fluide de l'état canvas global au sous-système sans rupture de navigation.
- **Feedbacks Visuels** : Auréoles d'agents colorées (Violet: Refactor, Bleu: Research, Vert: Doc, Rouge: Sentinel).
- **Certification** : Badge SHA-256 vert/cyan à chaque cristallisation d'atome ou d'orbe.

---

## 🗺️ PHASE G : Projection Spatiale Finale sur le Canvas

Les Sous-Systèmes vivent sous forme de `VceSubsystemNode` dans le même espace cartésien 2D/3D ReactFlow, conservant leurs connexions et leur position tout en permettant des interactions locales riches (Exploration, Édition Plein Écran, Comparaison Multi-Fichiers).
